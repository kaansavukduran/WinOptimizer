# WinOptimizer Aion 5.0.0-beta.1

Windows x64 ön sürümü. İki gerçek paketle güncelleme doğrulamasının önceki sürümüdür. Yeni kurulum için 5.0.0 sürümünü tercih edin.

[Windows x64 Setup.exe](https://github.com/kaansavukduran/WinOptimizer/releases/download/v5.0.0-beta.1/WinOptimizer-Aion-5.0.0-beta.1-Windows-x64-Setup.exe) dosyasını indirip çift tıklayın. Başlat → WinOptimizer Aion ile açın.

Türkçe/English; Aion kare animasyonları; güvenli temizlik/geri alma; sürücü merkezi; başlangıç ve sistem araçları; ayrı tema, font, yazı boyutu ve %80–%200 ölçek; yerel kayıt ve imzalı güncelleme doğrulaması.

Bu pakette Windows Authenticode sertifikası yoktur. Güncelleme metadatası Ed25519 ile doğrulanır. Sürücü yedeği yalnızca üçüncü taraf sürücü deposunu kapsar. Güvenli depoya taşıma alan açmaz; kalıcı silme geri alınamaz. Windows 10 22H2 / Windows 11 x64 içindir.

English: Windows x64 baseline pre-release for installed updater verification. Prefer 5.0.0 for new installations. Download Setup.exe, double-click, then open from Start. No Authenticode certificate; update metadata is Ed25519 authenticated. Local settings and history survive updates.
